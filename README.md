
# Development Library Desktop Apllication using JavaFX

Repositori ini berisi sourcode aplikasi destop IT Del library menggunakan JavaFX

## Run Locally

Clone the project

```bash
  git clone https://github.com/khensin166/Project_PBO.git
```

Go to the project directory

```bash
  cd Project_PBO
```

Run in Compiler

```bash
  Debug Application
```
